# 4.4 A：warp specialization

以原 4.3 S=3 源码为基线，另存 [`04a_warp_specialized.cu`](inputs/m4_gemm/04a_warp_specialized.cu)。此版保持 128×64×64 tile、3 个 A/B stage、原 TMEM 读回及 host 对拍；warp 0 的 lane 0 连续发 TMA，warp 1 的 lane 0 等 `full` 后发 `tcgen05.mma` 并向 `empty` commit。生产者等上一轮 `empty` 才复用 stage，消费者等本轮 `full` 才使用它。其余线程参与最终 TMEM 读回。没有修改用户的 `03_pipeline.cu`。

2026-09-23，在同一次 Modal B300 SXM6 AC 分配中以 `sm_100f` 强制重编两版。候选在 128×64×64、128×64×128、256×192×256、256×4096×16384 四个形状全部 `PASS(bad=0)`；4096³ 与基线交替各跑三次，也全部 PASS。每个程序 `timeout -k 2s 5s`，无超时或自动重试。完整构建/运行输出及源码 SHA256 在 [`run.json`](run.json)，运行器与上传源码在本目录。

| 4096³，TFLOPS | 第 1 对 | 第 2 对 | 第 3 对 | 中位数 |
|---|---:|---:|---:|---:|
| 4.3 S=3 基线 | 474.3 | 474.2 | 473.7 | 474.2 |
| 4.4A warp 分工 | 563.2 | 561.3 | 562.0 | 562.0 |

同卡交替中位数提升 **18.5%**。这是此配置下的实测增益，值得保留并作为后续叠加起点；未锁频的三对普通计时仍不是跨其他形状的通用加速保证。薄矩阵形状单次结果为 329.5 TFLOPS，但本轮未跑它的同卡基线，不据此给出薄形状提升百分比。
